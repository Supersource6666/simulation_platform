# 车轨耦合验证记录

日期：2026-09-15。环境：Windows、MSVC Release、现有 Chrono Core 构建树。

## 结论

首版 **10DOF 车辆 + Euler–Winkler 梁 + Hertz 单边接触 + 预测校正** 已编译并完成单模块、双向耦合和数值一致性检查。
单轨、双轨、变速度、实测不平顺和输入快照复算均有实际运行验证。
这是数值基线；**加速度与三维模型仍未全面通过验证，不能当作已标定车辆预测模型。**

默认解析模态数设为 320。相对 320 阶参考，640 阶的轮轨力最大 NRMSE 约 0.0015%，但最敏感的轮对加速度 NRMSE 仍约 5.20%。
240 单元 FEM 的轮轨力最大 NRMSE 约 0.3192%，钢轨触点位移最大 NRMSE 约 0.148%；其加速度误差明显更大。
因此轮轨力的 1% 条件已在该 FEM 网格上满足，加速度不能一并宣布收敛。

## 自动检查

`coupled_physics_checks` 通过，覆盖：

- 10DOF 车辆固定轮对条件下的悬挂固有频率正性、谐波接触力频域对照、规定正弦轮对位移对照。
- 单梁静挠度解析式 `PL³/(48EI)`、简支端点、多个点载荷叠加。
- Hermite 梁 FEM 的静挠度解析对照。
- 模态常力精确递推，无阻尼/临界阻尼/过阻尼静态保持。
- 恒速移动荷载的解析响应、变速移动荷载的独立 Duhamel 数值积分。
- Hertz 无拉力、空间不平顺导数、速度精确分段积分。
- 联合静平衡、总重力平衡、静态漂移、对称双轨、变速度耦合。
- 大不平顺绝对偏置下的静平衡、脱离/再接触、未收敛整步回滚。
- 大外部步长实际细分、细分后轮轨力与细外部步长结果对照。

额外端到端检查通过：

- 双轨 + 实测轨道 + 从停车开始的变速输入，运行 0.05 s。
- 左右轮轨力确有差异，确认两条实测垂向通道分别进入模型。
- 使用输出目录中的 `coupled_config.json` 复算，`response.csv` 逐字节一致。
- 拒绝覆盖已有输出，拒绝 NaN 时间步和未知轨道后端，错误参数不创建结果目录。

这些检查的工况和门槛是数值回归用途，不是舒适度、运行安全或实车性能标准。

## 2 秒扫描

配置为现有 25T YZ 满载质量/悬挂参数、规定 120 km/h、窗口正弦不平顺、单轨四接触。
轨道/Hertz/质心点头惯量仍为说明文档中列出的假设。
参考为 320 模态、外部 `dt=1e-4 s`，相位分辨率上限 0.2。

| 工况 | 最大轮轨力 NRMSE | 力误差 <1% |
|---|---:|---|
| 640 模态 / 320 模态 | 0.0015% | 是 |
| 5 模态 / 320 模态 | 0.0332% | 是 |
| 10 模态 / 320 模态 | 0.0383% | 是 |
| 20 模态 / 320 模态 | 0.0717% | 是 |
| 40 模态 / 320 模态 | 0.1199% | 是 |
| 80 模态 / 320 模态 | 0.3079% | 是 |
| FEM 120 单元 / 320 模态 | 3.7802% | 否 |
| FEM 240 单元 / 320 模态 | 0.3192% | 是 |

低模态数的力误差并不单调。一个可能原因是平顺工况中静轮重占主导，而不同截断模态数引入不同的空间误差；单凭这项扫描还不足以确认各因素的贡献。
不能据该列推荐仅用 5 阶模态：80 阶触点轨道位移误差约 20.9%，部分加速度相对误差也很大。
完整报告同时保留各输出的绝对 RMSE、参考 RMS 和最大误差，便于识别小参考量导致的相对误差放大。

外部步长 `0.01,0.001,0.0005,0.0001 s` 均成功运行。
它们的轮轨力误差在表格四位小数的百分比格式下均显示 0.0000%；**这些运行都使用频率约束内部子步**，不意味着直接使用 0.01 s 积分也准确。

参考运行实际内部步数为 260000，最小内部步长约 `7.6923e-6 s`。
将相位上限从 0.2 减至 0.1 后，内部步数为 500000，最小内部步长 `4e-6 s`：

| 内部步细化指标 | 最大 NRMSE |
|---|---:|
| 轮轨力 | 约 0.0000124% |
| 车辆各自由度加速度 | 约 0.2291% |
| 触点轨道位移 | 约 0.0000104% |

该平顺扫描没有离轨事件，因而不能给出事件时间收敛结论。
强不平顺脱离/再接触由独立物理检查覆盖，但尚未完成其跨模态、网格、内部步长的事件时间联合收敛研究。

原始结果位于本工作区：

- `build/coupled_validation_stable/validation.json`：完整逐通道误差和工况参数。
- `build/coupled_validation_stable/validation.md`：扫描汇总。
- `build/coupled_phase_half/comparison.json`：独立内部步细化结果。
- `build/coupled_smoke_twin`、`build/coupled_smoke_replay`：实测双轨及快照复算。
- `build/coupled_final_default`：最终默认配置运行。

早期 `build/coupled_validation` 是引入频率约束前的诊断结果，已被后续结果替代，不能作为当前实现的验收记录。

## 计时

该次 2 秒参考运行的求解加 CSV 输出墙钟时间约 14.6 s；640 模态运行约 85.8 s（包含程序启动等）。
本版没有硬实时保证，输出计时也不等于纯求解器 CPU 耗时。两种轨道后端共用时间传播器，FEM 对照主要验证独立空间离散。
后续优化应先以稳定性和误差验收为前提，再比较缓存、输出降采样、振型查表及内存复用的收益。
